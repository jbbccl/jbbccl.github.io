系统debain12 nodejs 20.18.0 npm 10.8.2

hexo环境

新建目录hexo，将hexo cli局部安装到这个目录
npx hexo 执行

部署到github

本地准备ssh
  • 登陆github创建仓库，名为name.github.io
  • 点击右上角头像->settings. 左边栏找到 SSH and GPG keys 点add ssh keys
  • 将~/.ssh/githubkey.pub的内容全部复制到框里，命名后add SSH key

在本地终端

连接成功则没问题

编辑blog下的_config.yml

/.ssh/config里指定密钥为/.ssh/github

参考文档中的一键部署hexo

访问名字.github.io
